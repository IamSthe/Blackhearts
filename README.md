# Blackhearts Wiki

Wiki estática inspirada na identidade visual do Blackhearts RP, pronta para publicação no GitHub Pages.

## Rodar localmente

Abra o `index.html` no navegador ou use uma extensão de servidor local do VS Code.

## Publicar no GitHub Pages

1. Envie os arquivos para a branch `main` do repositório `IamSthe/Blackhearts`.
2. No GitHub, abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **GitHub Actions**.
4. O workflow `.github/workflows/pages.yml` fará o deploy a cada push.

O endereço esperado será `https://iamsthe.github.io/Blackhearts/`.
